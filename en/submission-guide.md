This guide applies to **weekly lecture notes, homework, project proposals, and final project reports**. Every submission must be stored in the appropriate location and registered on the course platform.

## 1. Required Accounts

Every student must have:

- A **Gmail account** for Google Drive.
- A **GitHub account** for submitting runnable code.
- A registered account on **[learn.spaiq.ai](https://learn.spaiq.ai)**.

Use your full name and student ID consistently so your submissions can be identified.

## 2. Written Materials: Google Drive

Upload the following materials to your Google Drive:

- Markdown source files (`.md`).
- PDF versions of your notes, homework, proposals, and reports.
- Supporting evidence, such as screenshots, diagrams, and experiment results.

Create one course folder and organize its contents by week or assignment. Use clear filenames, for example:

`StudentID_Name_Week03_LectureNotes.pdf`

Share the course folder with **[tiejianluo@gmail.com](mailto:tiejianluo@gmail.com)**, granting **Viewer** access. Check that all submitted files are accessible through the shared folder.

## 3. Code and Documentation: GitHub

For submissions involving programming, upload the following to your GitHub repository:

- Runnable source code.
- A `README.md` explaining the work, required dependencies, setup instructions, and how to run it.
- Relevant configuration files and sample inputs needed to reproduce the results.

Organize the repository by assignment or project. Ensure the instructor can access and review it. For a private repository, invite **[tiejianluo@gmail.com](mailto:tiejianluo@gmail.com)** and use read-only permissions where supported.

## 4. Submission Record: Course Platform

For **every** set of lecture notes, homework assignment, project proposal, or final report, also submit a record through your registered account on **[learn.spaiq.ai](https://learn.spaiq.ai)**.

Include:

- Your full name and student ID.
- The submission type, title, and corresponding week or assignment number.
- A brief summary of the submitted work.
- The Google Drive link.
- The GitHub link, when code is required.

Google Drive and GitHub contain the materials; the course platform records what you submitted and where it can be reviewed.

## 5. Before Submitting

Check that:

- All required files have been uploaded.
- Google Drive permissions allow the instructor to view the files.
- The GitHub code runs using the instructions in `README.md`.
- The course-platform record contains the correct links and summary.
